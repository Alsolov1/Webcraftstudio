WEBCRAFT ADMIN - setup

Files:
- index.html: original website, preserved.
- admin/index.html: administrator sign-in at https://YOUR-DOMAIN/admin/
- admin/dashboard.html: protected dashboard.
- admin/supabase-setup.sql: database table, RLS policy, and administrator allow-list insertion.

Setup steps:
1. In Supabase -> Authentication -> Users -> Add user, create the administrator email/password.
2. Open Supabase -> SQL Editor. Open admin/supabase-setup.sql, replace admin@example.com with the exact administrator email, and run it.
3. In Supabase -> Authentication -> URL Configuration, set Site URL to https://webcraftdz.online and add https://webcraftdz.online/admin/** to Redirect URLs if required.
4. Upload the contents of this ZIP to the root of the website, preserving the existing CNAME file.
5. Open https://webcraftdz.online/admin/ and sign in using the administrator account created in step 1.

Security notes:
- The publishable key is designed for browser use. Never put a service_role or secret key in these files.
- The admin_users table has RLS enabled. Authenticated users can only read their own admin record. There is no public insert policy.
- Do not enable public sign-up for this admin-only flow.
- This first stage provides administrator authentication and a starter dashboard. It does not yet move Formspree submissions into Supabase or provide request-management features.
