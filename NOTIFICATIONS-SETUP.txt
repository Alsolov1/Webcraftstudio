WEBCRAFT — NOTIFICATIONS SETUP
================================

The updated admin dashboard checks for new requests every 15 seconds while it is open.
It displays an unread count and a new-request notice. It does not require changing the
existing customer_requests table or exposing any secret in the website.

EMAIL ALERTS (Resend + Supabase Database Webhook)
-------------------------------------------------

Recipient:
  contact@webcraftdz.online

Sender:
  WEBCRAFT Notifications <notifications@webcraftdz.online>

A. Verify the sending domain in Resend
1. Create/sign in to a Resend account: https://resend.com/
2. Add the domain: webcraftdz.online
3. Resend will show DNS records (typically SPF and DKIM; sometimes additional records).
4. Add those exact records in the DNS manager for webcraftdz.online (Hostinger DNS if
   that is where the domain's DNS is managed).
5. Wait until Resend reports the domain as verified.
   Do not invent DNS values; copy the values shown by Resend.

B. Deploy the Supabase Edge Function
1. In Supabase, open Edge Functions and create a function named:
     send-new-request-email
2. Copy the full source from:
     supabase/functions/send-new-request-email/index.ts
3. Deploy the function. Set JWT verification OFF for this function because it is called
   by the Supabase Database Webhook. The function independently checks WEBHOOK_SECRET.
4. In the function Secrets settings, add:
     RESEND_API_KEY = (the API key created in Resend)
     WEBHOOK_SECRET = (create a long random secret; use the same exact value in step C)
   Never put either value in index.html or share it in chat.

C. Create the Database Webhook
1. Supabase Dashboard -> Database -> Webhooks -> Create a new webhook.
2. Name: webcraft-new-request-email
3. Table: public.customer_requests
4. Events: INSERT only.
5. Type: Supabase Edge Functions (or HTTP request, depending on dashboard version).
6. Function/URL:
   https://dtuocmximdmzwjehzbkn.supabase.co/functions/v1/send-new-request-email
7. Add a custom header:
     x-webhook-secret: (the same WEBHOOK_SECRET set in step B)
8. Save the webhook.

D. Test
1. Submit one new test request from https://webcraftdz.online/.
2. Keep https://webcraftdz.online/admin/dashboard.html open. Within about 15 seconds,
   the unread count and new-request notice should update.
3. Confirm an email arrives at contact@webcraftdz.online (check Spam/Junk too).
4. If the email does not arrive, check Supabase Edge Function logs and Resend email logs.

IMPORTANT
- The dashboard notification is visible only while the admin dashboard is open.
- Browser desktop notifications are optional and depend on browser permission.
- Email delivery requires a verified sender domain and a working recipient mailbox.
- Do not share the Resend API key or WEBHOOK_SECRET.
- Existing form submission remains independent: a temporary email delivery failure does
  not undo a request already saved in Supabase.
